# 外部デコーダー

選局した TS を、利用者が用意した外部のコマンド（デコーダー）に通してから、再生・字幕・録画へ回せる。デコーダーはこのアプリには含まれない。

```
coax tune --ch N ──▶ デコーダー ──▶ 中継（字幕・録画）──▶ mpv
```

## Homebrew で入れる

macOS 向けにビルドできるようにした libaribb25 を、tap の Formula で入れられる（ソースからビルドする）。

```sh
brew install bellx2/tap/libaribb25
```

`/opt/homebrew/bin/arib-b25-stream-test` に入り、設定しなくてもこれを使う。macOS 向けの手当ては [bellx2/libaribb25](https://github.com/bellx2/libaribb25) の README を参照。

## 指定のしかた

次の順に探し、最初に見つかったものを使う。どれも無ければデコーダーを通さない。

1. 起動引数 `--decoder <path>`
2. 設定画面（⌘,）の「チューナー」タブの「外部デコーダー」で選んだもの（保存して次の起動でも使う）
3. Homebrew で入れた `/opt/homebrew/bin/arib-b25-stream-test`

設定画面で選び直したものは、次の選局から使う。

## つなぎ方

- 引数なしで起動し、stdin から TS を読んで、stdout に TS を書くものを指定する（引数や環境変数が要るなら、それを付けて起動するスクリプトを指定する）
- デコーダーがあると、アプリは `coax pcsc --socket $TMPDIR/CoaxPlayer/pcscd.comm` を起動し、そのソケットを環境変数 `PCSCLITE_CSOCK_NAME` でデコーダーに渡す。`coax pcsc` が準備できてから選局し、途中で終わったときはデコーダーを通さずに再生する
- 再生中にデコーダーが終わったとき（カードが無いと、TS を何も出力せずに終わる）は、デコーダーの stderr の最後の行を画面下に出し、デコーダーを通さずに選局し直してワンセグを再生する
- そのあとは選局のたびに `coax card --status` でカードを確かめ、差し直されていればデコーダーを通す状態に戻る。デコーダーの設定を変えるか、「coax を再起動」を押しても戻る
- デコーダーの stderr は、終わったときの最後の行のほかは画面に出さない（`--debug` では全部 stderr に出す）

## 制限

- デコーダーによっては、PAT の無い TS（ワンセグしか受からないとき）では何も出力しないことがある
