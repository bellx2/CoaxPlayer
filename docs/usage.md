# 使い方

1. 設定画面（⌘,）の「チャンネルスキャン」で範囲（地上 UHF 13〜52、ケーブル）を選び、「スキャン開始」を押す。結果は `~/Library/Application Support/CoaxPlayer/scan.json` に保存され、最初のページにチャンネル一覧（番号・局ロゴ・局名・今の番組）が 2 列で出る
2. 一覧のチャンネルを押すと、映像のページに切り替わって再生する。「チャンネル一覧」（Esc、delete）で一覧に戻ると、再生を止める

一覧の番組は、起動時・スキャンの後・一覧に戻ったとき・右上の「番組情報を更新」（矢印が回るアイコン）を押したときに、全チャンネルを順に短く選局して集める（1 チャンネル 2〜4 秒）。そのとき、ワンセグの映像の 1 コマを小さなプレビューにして、カードの左に出す（ワンセグの無い局は灰色のまま）。プレビューは保存し、次の起動ではまず前回のものを薄く出し、取り直せた局から普通に出す。その間にチャンネルを選ぶと、集めるのをやめて再生する。

一覧の左上には、チューナーのデバイスの状態（見つかったデバイスの名前、見つからなければ理由）を出す。起動時に `coax list --tuners` で確かめ、見つかったときだけ番組を集める。横の「デバイスを再スキャン」で確かめ直し、「coax を再起動」で coaxd（と外部デコーダー用の coax pcsc）を止めて立て直す。デバイスを差し直したのに見えないときに使う。

再生中は、映像のすぐ下にチャンネル（局ロゴと局名）と今の番組（放送時間と番組名）を出す。局ロゴは放送で数分おきに送られてくるので、初めて見るチャンネルではしばらく出ない（その間は灰色の枠にテレビの印を出す）。一度受け取ったものは `~/Library/Application Support/CoaxPlayer/logos/` に保存し、次からはすぐ出す。ウィンドウを小さくして映像の幅が 560 ポイントより狭くなるときは、この行を出さずに、その分だけ映像を大きくする。

数字キー（テンキーも）でも、リモコンの番号で選局できる。10 以上の番号は続けて打つ（1 桁目の後、1 秒待つ）。

映像のページの右上のアイコン（カーソルを乗せると名前が出る）:

| ボタン | 動作 |
| --- | --- |
| 録画（丸） | 再生中の番組を `~/Movies/coax/` に TS で録画する。設定画面の「録画の変換」に ffmpeg の引数を入れておくと、止めたあとに変換もする |
| 字幕（吹き出し） | 字幕の表示を切り替える（最初は非表示。最後の設定を次の起動でも使う） |
| 音声（主・副・主副） | 二か国語や解説の番組（デュアルモノ）で鳴らす音声を、主音声・副音声・主と副（左右）の順に切り替える。普通のステレオの番組では変わらない |
| ワンセグ（1） | フルセグを見られるときも、ワンセグにする。外部デコーダーを通していない（無い、カードが無いなど）ときはワンセグしか見られないので、点いたまま押せない |

字幕・音声・ワンセグの設定は、チャンネルを替えても保つ。

録画の変換の引数では、`{in}` が録画した TS、`{out}` が拡張子を除いたパス、`{video}`・`{audio}` が止めた時点で再生していた映像と音声（`-map` に渡す形）に置き換わる。空白で区切るので、引用符は使えない。「例を入れる」で入るのは、主音声だけの MP4 を作る引数（`-dual_mono_mode main -i {in} -map {video} -map {audio} -c:v copy -c:a aac -b:a 128k -movflags +faststart {out}.mp4`）。
画面下の行には、選局中やエラーのメッセージを出す。受信状態の詳細（CNR、信号の強さ、ビットレート、エラー数など）は、設定画面（⌘,）の「デバッグ」で「画面下に受信状態の詳細を表示」をオンにしたときだけ出す（最初はオフ。最後の設定を次の起動でも使う）。
一覧を作り直すときも、設定画面からスキャンし直す。途中で中止したときは、次は続きから調べる。

ワンセグは、macOS 26 以降ではノイズ除去と超解像で高精細にして表示する。

チャンネルは `scan.json` にあるものからしか選べない。

## 更新

起動したときに（1 日 1 回まで）GitHub の最新の Release を確かめ、新しい版があれば、メニューバーの「CoaxPlayer」に「新しい版 <版> に更新…」を出す。
押すと、Homebrew で入れていれば `brew update` と `brew upgrade --cask coaxplayer` で更新して起動し直す。Homebrew で入れていなければ、Release のページを開く。
確かめられなかったときは何も出さず、次の起動で試す。

## 起動引数

```sh
# 起動と同時に 27ch を再生する
CoaxPlayer --ch 27

# 外部のデコーダーを指定する
CoaxPlayer --decoder /path/to/decoder.sh

# 録画した TS ファイルを再生する
CoaxPlayer /path/to/file.ts
```

| 引数 | 意味 |
| --- | --- |
| `--coax <path>` | 起動する coax のパス。省略時は実行ファイルと同じ場所の `coax`、無ければ PATH 上の `coax` |
| `--scan <path>` | チャンネル一覧にする `coax scan` の結果。無ければここに作る。省略時は `~/Library/Application Support/CoaxPlayer/scan.json` |
| `--decoder <path>` | 選局した TS を通す外部のデコーダー（[decoder.md](decoder.md)）。設定画面の指定より優先する |
| `--ch <n>` | 起動直後にこのチャンネルを再生する（`scan.json` にあるもの） |
| `--record` | `--ch` で選局したものを、そのまま録画する |
| `--debug` | mpv のログと、1 秒ごとの状態（再生位置、描画フレーム数など）を stderr に出す |
| `<file>` | ファイルを再生する（`--ch` が無いとき） |

`.app` の中の実行ファイルは `CoaxPlayer.app/Contents/MacOS/CoaxPlayer`。
