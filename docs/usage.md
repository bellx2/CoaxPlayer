# 使い方

1. 設定画面（⌘,）の「チャンネルスキャン」で範囲（地上 UHF 13〜52、ケーブル）を選び、「スキャン開始」を押す。結果は `~/Library/Application Support/CoaxPlayer/scan.json` に保存され、一覧の先頭の局を見始める
2. 画面は視聴画面だけで、起動すると前回最後に見ていた局を見始める（初めては一覧の先頭の局）。局は番組表の局名、数字キー、左右の矢印キーで替える

視聴画面の左上にはチューナーのデバイスの状態（見つかったデバイスの名前、見つからなければ理由）を出す。起動時に `coax list --tuners` で確かめ、見つかったら見始める。横の「デバイスを再スキャン」で確かめ直し、「coax を再起動」で coaxd（と外部デコーダー用の coax pcsc）を止めて立て直す。「coax を再起動」は、デバイスを差し直したのに見えないときに使う。

再生中は映像のすぐ下にチャンネル（局ロゴと局名）と今の番組（放送時間と番組名）を出す。局ロゴは放送で数分おきに送られてくるので、初めて見るチャンネルではしばらく出ない（その間は灰色の枠にテレビの印を出す）。一度受け取ったものは `~/Library/Application Support/CoaxPlayer/logos/` に保存し、次からはすぐ出す。ウィンドウを小さくして映像の幅が 560 ポイントより狭くなるときは、この行を出さずに、その分だけ映像を大きくする。

視聴画面の上の「番組表」（カレンダーのアイコン）か G キーで、映像の下半分に番組表を半透明で重ねる。もう一度押すか、映像を押すと閉じる。局を横に、時刻を縦に並べ、1 日（5 時から翌 5 時）ずつ見る。上の二重の矢印で前・次の日へ移る（今日から、番組表のある最後の日まで）。開くと見ている局の列を横の真ん中に寄せ、今日なら今の時刻（赤い線）を縦の真ん中に出す（ほかの日は 5 時から）。放送中の番組は色を変える。局名を押すとその局へ切り替える。見ている局の局名は青くし、下に線を引く。チャンネルを替えても番組表は開いたままにする。

番組表は、そのチャンネルを見ている間に放送から集める（選局して約 1 分で 8 日分）。地上波の放送には同じチャンネルの局の番組表しか入っていないので、まだ見ていない局の列は空になる。集めた番組表は `~/Library/Application Support/CoaxPlayer/guide.json` に保存し（チャンネルを替えたとき、終了したとき）、次の起動でも使う。終わって 1 日たった番組は消す。

数字キー（テンキーも）でも、リモコンの番号で選局できる。10 以上の番号は続けて打つ（1 桁目の後、1 秒待つ）。再生中は上下の矢印キーで音量を 5 ずつ変え、左右の矢印キーで一覧の並び（リモコンの番号の順）の前・次のチャンネルへ切り替える（端からは反対の端へ回る）。M キーでミュートを、I キーで番組詳細のパネルを、G キーで番組表を切り替える。

映像のページの右上には、次のアイコンのボタンがある（カーソルを乗せると名前が出る）。

| ボタン | 動作 |
| --- | --- |
| 番組表（カレンダー） | 映像の下半分に番組表を半透明で重ねる・閉じる（G キーでも切り替える） |
| 番組詳細（i の丸） | 映像の右に重ねて、今の番組の詳細のパネルを開く・閉じる（I キーでも切り替える）。映像を押しても閉じる。番組の説明と、放送に入っていれば「番組内容」「出演者」などの詳しい説明を出す。文中の URL（http・https。全角で書かれたものも）はリンクになり、クリックするとブラウザで開く。ワンセグの番組情報には詳しい説明が無いことが多い。開いたかどうかは次の起動でも使う |
| 録画（丸） | 再生中の番組を `~/Movies/coax/` に TS で録画する。設定画面の「録画の変換」に ffmpeg の引数を入れておくと、止めたあとに変換もする |
| ミュート（スピーカー） | 音を消す・戻す（M キーでも切り替える）。チャンネルを替えても保つが、次の起動には持ち越さない |
| 音量（スライダー） | 0〜100 で音量を変える（上下の矢印キーでも 5 ずつ変える）。動かすとミュートを解く。最後の音量を次の起動でも使う |
| 字幕（吹き出し） | 字幕の表示を切り替える（最初は非表示。最後の設定を次の起動でも使う） |
| 音声（主・副・主副） | 二か国語や解説の番組（デュアルモノ）で鳴らす音声を、主音声・副音声・主と副（左右）の順に切り替える。普通のステレオの番組では変わらない |
| ワンセグ（1） | フルセグを見られるときも、ワンセグにする。外部デコーダーを通していない（無い、カードが無いなど）ときはワンセグしか見られないので、点いたまま押せない |

字幕・音声・ワンセグの設定はチャンネルを替えても保つ。

録画の変換の引数では、`{in}` が録画した TS、`{out}` が拡張子を除いたパス、`{video}`・`{audio}` が止めた時点で再生していた映像と音声（`-map` に渡す形）に置き換わる。空白で区切るので、引用符は使えない。「例を入れる」で入るのは、主音声だけの MP4 を作る引数（`-dual_mono_mode main -i {in} -map {video} -map {audio} -c:v copy -c:a aac -b:a 128k -movflags +faststart {out}.mp4`）。

画面下の行には選局中やエラーのメッセージを出す。受信状態の詳細（CNR、信号の強さ、ビットレート、エラー数など）は、設定画面（⌘,）の「デバッグ」で「画面下に受信状態の詳細を表示」をオンにしたときだけ出す（最初はオフ。最後の設定を次の起動でも使う）。

設定画面の「チューナー」で、使うチューナーを coax と PIX-DT295（pix-userland）から選ぶ。PIX-DT295 では pix-userland のフォルダーも指定する（[dt295.md](dt295.md)）。どちらも次の起動でも使う。

チャンネル一覧が無いときは、映像の所に「設定を開いてスキャン」を出す。一覧を作り直すときは、設定画面の「チャンネルスキャン」でスキャンし直す。途中で中止したときは、次は続きから調べる。

ワンセグは macOS 26 以降ではノイズ除去と超解像で高精細にして表示する。

チャンネルは `scan.json` にあるものからしか選べない。

## 更新

起動したときに（1 日 1 回まで）GitHub の最新の Release を確かめ、新しい版があれば、メニューバーの「CoaxPlayer」に「新しい版 <版> に更新…」を出す。
押すと、Homebrew で入れていれば `brew update` と `brew upgrade --cask coaxplayer` で更新して起動し直す。Homebrew で入れていなければ、Release のページを開く。
確かめられなかったときは何も出さず、次の起動で試す。

## 起動引数

```sh
# 起動と同時に 27ch を再生する
CoaxPlayer --ch 27

# 外部のデコーダーを指定する
CoaxPlayer --decoder /path/to/decoder.sh

# 録画した TS ファイルを再生する
CoaxPlayer /path/to/file.ts
```

| 引数 | 意味 |
| --- | --- |
| `--coax <path>` | 起動する coax のパス。省略時は実行ファイルと同じ場所の `coax`、無ければ PATH 上の `coax` |
| `--scan <path>` | チャンネル一覧にする `coax scan` の結果。無ければここに作る。省略時は `~/Library/Application Support/CoaxPlayer/scan.json` |
| `--decoder <path>` | 選局した TS を通す外部のデコーダー（[decoder.md](decoder.md)）。設定画面の指定より優先する |
| `--ch <n>` | 起動直後にこのチャンネルを再生する（`scan.json` にあるもの） |
| `--record` | `--ch` で選局したものを、そのまま録画する |
| `--debug` | mpv のログと、1 秒ごとの状態（再生位置、描画フレーム数など）を stderr に出す |
| `<file>` | ファイルを再生する（`--ch` が無いとき） |

`.app` の中の実行ファイルは `CoaxPlayer.app/Contents/MacOS/CoaxPlayer`。
