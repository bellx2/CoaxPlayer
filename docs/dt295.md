# PIX-DT295

ピクセラの PIX-DT295 は coax が対応していないので、[pix-userland](https://github.com/Khronos31/pix-userland) の `pixd` と `pix-ts` で受信し、その TS を coax に通して再生する。

```
pixd（DT295 を受け持つ）
pix-ts -c T27 -t - -o - ──▶ coax tune --input - --stats --program ──▶ 中継（字幕・録画）──▶ mpv
```

## 用意するもの

- pix-userland の配布アーカイブを展開したフォルダー。`pixd`、`pix-ts`、`firmware/dt295.bin` があること。選局を速くする変更（USB 転送を 8 KiB × 64 本にする）を入れた fork（[bellx2/pix-userland](https://github.com/bellx2/pix-userland) の `perf/dt295-tune-latency`）を使うと、選局から映るまでが約 9 秒から 2〜3 秒になる
- チャンネル一覧（`scan.json`）。DT295 ではまだスキャンできないので、coax のチューナーでスキャンしたものを使う

pix-userland とファームウェアはこのアプリに含まれない。`dt295.bin` はメーカー由来のデータを含み、再配布が制限されているためである。

## 設定

設定画面（⌘,）の「チューナー」で「PIX-DT295（pix-userland）」を選び、「フォルダーを選ぶ…」で pix-userland のフォルダーを指定する。どちらも次の起動でも使う。

## 動き

- チューナーを PIX-DT295 にすると、`pixd --list-json` で DT295 の USB の位置（`3-1.1` など）を調べ、`pixd --device usb:<位置> --firmware <フォルダー>/firmware/dt295.bin --instance coaxplayer --runtime-dir $TMPDIR/CoaxPlayer-pix` を起動する。`pixd ready` の行が出たら選局できる。それより前に選んだ局は、準備ができてから選局する
- アプリが落ちて残った `pixd` は DT295 を持ったままになるので、次に起動するときに止める
- 選局すると `pix-ts --receiver 0 -c T<物理チャンネル> -t - -o -` を起動し、その出力を `coax tune --input - --stats --program` の stdin につなぐ。coax の stderr の行（番組と受信状態）は、coax のチューナーで受信したときと同じように使う
- DT295 の TS はスクランブルが解けているので、外部デコーダーも `coax pcsc` も使わず、フルセグを再生する
- 止めるときは `pix-ts` を先に止める。`coax tune --input` は入力が終わると自分で終わる
- 一覧の今の番組は集めるが、プレビューは集めない。1 局の選局に 2〜3 秒かかり、プレビューまで待つと一覧がそろうのが遅れるため
- 映像が出ないときに選び直す見張りは、選局したときではなく、最初の受信状態の行が届いたとき（TS が流れ始めたとき）から 5 秒で数える。`coax tune --input` はデータが届くまで受信状態の行を出さないので、選局にかかる時間が pix-userland の版で違っても同じように働く
- 番組集めの時間切れは、上流の pix-userland でも間に合うよう 15 秒にしている（coax のチューナーでは 10 秒）
- アプリを終了するときに `pixd` を止める

## 制限

- 選局してから映るまで 2〜3 秒かかる（上流の pix-userland では約 9 秒）。pix-ts が PSI（PAT・PMT・CAT）を集めて PID の割り当てを決めてから流し始めるためである
- 地上波（13〜62ch）だけを受ける。ケーブルと衛星は受けない
- 受信状態の行には、ロック、CNR、信号の強さ、ドロップ数が出ない（coax は入力の TS しか見ないため）
- 設定画面の「チャンネルスキャン」は coax のチューナーで行う。DT295 だけではスキャンできない
- macOS では、差し込み口によって DT295 の USB の位置を読めず、`pixd` が DT295 を選べないことがある。デバイスの状態に「USB の位置を読めません」と出たら、別の差し込み口に挿し直す
