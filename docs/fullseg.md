# フルセグ

フルセグの再生には、利用者が別に用意するデコーダーが要る。このアプリには含まれない。
`--decoder` で指定すると、選局した TS をそれに通してから再生する。指定が無くても、Homebrew で入れた `/opt/homebrew/bin/arib-b25-stream-test` があれば自動で使う。

```
coax tune --ch N ──▶ デコーダー ──▶ 中継（字幕・録画）──▶ mpv
```

## デコーダーとのつなぎ方

- 引数なしで起動し、stdin から TS を読んで、stdout に TS を書くものを指定する（引数や環境変数が要るなら、それを付けて起動するスクリプトを指定する）
- `--decoder` を指定すると、アプリは起動時に `coax pcsc --socket $TMPDIR/coax-player/pcscd.comm` を起動し、そのソケットを環境変数 `PCSCLITE_CSOCK_NAME` でデコーダーに渡す。`coax pcsc` が準備できてから選局する
- デコーダーの stderr は画面に出さず、異常終了したときだけ最後の行を画面下に出す（`--debug` では全部 stderr に出す）

## ワンセグとフルセグの選択

- デコーダーを指定しているときはフルセグを再生する。映らないときは、左の「ワンセグ」をオンにする
- 「ワンセグ」は選局し直さずに映像と音声のトラックだけを替える。デコーダーは動いたままなので、CPU の負荷は下がらない
- デコーダーを指定しないときはワンセグを再生する
- ファイルを再生するときは、解析で映像の大きさが分かればフルセグを選ぶ

## 負荷

フルセグ（MPEG-2 1440x1080i）の再生は、インターレース解除を含めて M4 Pro の 1 コアの約 50%。

## 制限

- デコーダーによっては、PAT の無い TS（ワンセグしか受からないとき）では何も出力しないことがある
